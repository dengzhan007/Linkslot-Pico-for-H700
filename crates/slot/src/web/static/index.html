使用说明

      
    
        
  1. 设备与手机 / 电脑需要连接同一个 WiFi。
    2. 
        
  2. 「存档」页可以预览即时存档缩略图、下载存档、用上传文件覆盖即时存档 / 电池存档，或删除本机存档；删除不影响云同步或远端备份。
    3. 
        
  3. 「云同步」页配置 WebDAV 后，可对单个存档单元执行 linkSlot sync；设备正在游戏或同步时写入会被拒绝。
    4. 
        
  4. 「游戏库」页可替换封面、ROM，也可给当前游戏上传介绍 `.txt` 和演示视频 `.mp4`；详情页可导出单个游戏，工具栏可按平台导出/导入包含 ROM、封面、介绍和视频的合集 ZIP。
    5. 
        
  5. 本服务无登录鉴权，仅限家庭局域网使用，请勿暴露到公网。
    6. 
        
  6. 设备 IP 变化（例如切换 WiFi）后，请用设备上显示的新地址重新访问。
