# X/Y 专项复测 — 2026-11-26 13:04 UTC

目的：第一轮 17 键测试里 X 与 Y 的先后顺序与指令表相反。为了排除“操作顺序记错”这种误判，单独再做一次只按 X/Y 的复测。

## 结论

前三次（操作者按的是 **X**）全部上报 **`307`**；后三次（操作者按的是 **Y**）全部上报 **`306`**。6 次按压 **6/6 一致**，没有任何抖动或交错。

也就是说，在这台机器上：

- 面板上标 **X** 的键 → evdev **`307`**
- 面板上标 **Y** 的键 → evdev **`306`**

而设备树里 `306` 属于 `keyX`（`PA3`）、`307` 属于 `keyY`（`PA2`）。所以 DT 的**节点名与 code 的对应本身没错**（`keyX`=306、`keyY`=307），错的是“`keyX` 这个节点对应面板上标 X 的那个物理键”这个假设 —— **`keyX`(306) 实际接的是面板上标 Y 的键，`keyY`(307) 接的是标 X 的键，两者互换**。

## 对第一轮记录的影响（修正）

第一轮 `KEY-EVENT-TEST.md` §4 第 1 条把“X 在 Y 之后”记为操作者按压顺序与指令表不符。结合本次 6/6 复测，更合理的解释是：操作者当时**确实先按了 X、再按了 Y**，但因为 X 实际发 `307`、Y 实际发 `306`，落盘顺序才显示成 `307` 在前、`306` 在后。因此那条应改判为**键位互换**，而不是操作顺序偏差。第一轮的原始字节不做任何修改，只更正解释。

## 影响面
