# linkSlot 中文定制版 · 用户手册

linkSlot 是面向 Anbernic H700 系列掌机的 Game Boy 系前端，基于上游
[Slot](https://github.com/slot-cfw/slot) 定制：支持 GBA / GB / GBC / FC / SFC / MD，
提供中文 / English 界面、Web 管理端、WebDAV 云存档同步、双人联机、卡带传输、
成就、前盖编辑、屏幕遮罩、金手指与扩展包。

- 当前版本：**v1.0.49**（2026-11-25 构建）
- 发布包：`linkslot-v1.0.49-h700.zip`
- 完整版本历史：见 [CHANGELOG.md](CHANGELOG.md)
- 扩展包格式与制作：见 [EXTENSION-PACKS-ZH-CN.md](EXTENSION-PACKS-ZH-CN.md)
- 从源码构建：见 [build/README.md](build/README.md)

> 本手册按 v1.0.49 的实际行为编写。v0.9.x 及更早版本的发布说明只保留在
> `CHANGELOG.md`，不再混进用户手册。

## 1. 功能一览

- **6 个机种**：GBA、GB、GBC、FC（Famicom / NES）、SFC（Super Famicom / SNES）、
  MD（Mega Drive / Genesis），每个机种有独立卡带架、封面、存档与画面设置。
- **中英双语**：设备端、Web 管理页、浏览器游玩页和 mod 共用
  `linkSlot/Config/language.txt`，切换后立即生效。
- **云同步**：WebDAV（可保存多个服务器、单选生效）；按 ROM 的 SHA-256 识别游戏，
  差量上传/下载、冲突保护、自动备份，游戏时长与成就也会合并到云端。
- **双人联机**：GBA 支持 mGBA 电缆、gpSP / armGBA netpacket；FC / SFC / MD 支持
  「一台主机两台手柄」式的单机双人联机。
- **卡带传输**：两台掌机之间传卡带，可选「仅卡带 / 仅存档 / 卡带＋存档」。
- **Web 管理端**：游戏库、存档、云同步、扩展包与 mod、文件、设置、成就、日志。
  手机或电脑连同一 WiFi 即可使用。
- **浏览器游玩**：GBA / GB / GBC / FC 可直接在浏览器里运行，电池存档自动读写。
- **成就**：15 个全局成就 + 每个 ROM 5 个通用成就 + RetroAchievements 成就扩展包。
- **外观**：卡带颜色、外壳、标签、前盖（Web 编辑器 + 设备托盘）、收藏金星、
  槽内蚀刻铭牌、主题、屏幕遮罩、机种背景图、壁纸与开机图。
- **游戏体验**：即时存档相册、金手指、TXT / EPUB 攻略、游戏介绍与演示视频、
  快进 / 倒带、连发、按键重映射。
- **维护**：WiFi 管理、SNTP 校时、合盖自动关机、只读卡修复、日志导出与清理。

## 2. 支持的机种与核心

### 2.1 机种与核心总表

| 机种 | ROM 目录 | 扩展名 | 随包核心 | 可选核心 | 联机 |
|---|---|---|---|---|---|
| GBA | `Games/GBA/` | `.gba` | mGBA、gpSP | armGBA（LSP 扩展包） | 2 人：mGBA 电缆；gpSP 无线；armGBA 电缆/无线 |
| GB | `Games/GB/` | `.gb` `.gbc` | mGBA | — | mGBA 电缆（以游戏支持为准） |
| GBC | `Games/GBC/` | `.gb` `.gbc` | mGBA | — | mGBA 电缆（以游戏支持为准） |
| FC | `Games/FC/` | `.nes` | fceumm | Nestopia（LSP 扩展包） | 单机双人（热点 / 同一 Wi-Fi） |
| SFC | `Games/SFC/` | `.sfc` `.smc` `.fig` | snes9x | supafaust（自行放入 / LSP 扩展包） | 单机双人（热点 / 同一 Wi-Fi） |
| MD | `Games/MD/` | `.md` `.gen` `.smd` `.bin` | Genesis Plus GX | — | 单机双人（热点 / 同一 Wi-Fi） |

补充说明：

- **GB / GBC 互认扩展名**：两者都接受 `.gb` 与 `.gbc`；请仍放进对应目录，
  卡带架按目录区分机种。
- **FC 只支持 `.nes`**：不支持 `.fds`（需要 BIOS 与换面按键，本版未接）。
- **MD 强制六键手柄**：即使 ROM 头没声明六键，也能使用 X / Y / Z 与 MODE。
- **SFC 的 X / Y 是正式按键**，不再作为连发键；FC / GB / GBC / GBA 的 X / Y
  仍可作连发 A / B（需在设置里开启连发）。
- **随包核心固定为 5 个**：mGBA、gpSP、fceumm、snes9x、genesis_plus_gx。
  Nestopia、supafaust、armGBA 不随版本包分发，需要扩展包或手动放入。
- 核心文件放在 `System/linkSlot/cores/<核心 id>/<核心 id>_libretro.so`。

### 2.2 画面与缩放

H700 屏幕为 720×480。默认按整数倍缩放：

- GBA：240×160，3 倍到 720×480；
- FC / SFC：256×224，2 倍居中（512×448，上下留黑边）；
- MD：320×224，2 倍居中（640×448）；
- GB / GBC：默认原始比例；在游戏内可切换拉伸/原始比例（见 7.5）。

### 2.3 核心选择

在主界面按 **START** 打开 PCB / 核心选择器：

- ←/→ 移动焦点，**A** 应用，**B** 返回；
- GBA 装有三颗核心时：第 1 槽固定 mGBA，第 2 槽是可热插拔的插座，板下托盘
  放备用芯片；在托盘上按 A 会与第 2 槽对调；
- GB / GBC / MD 只有一个核心时，板面只作信息展示，A/B 关闭；
- 选择会按游戏记在 `linkSlot/Config/selected_core.txt`；
- GBA 最后用过的备用核心记在 `linkSlot/Config/core_tray.txt`；
- 核心被卸载后，使用它的卡带会暂时回退到该机种默认核心并提示一次，重新安装
  后恢复原来的选择。

### 2.4 可选核心

| 核心 | 机种 | 获取方式 | 说明 |
|---|---|---|---|
| armGBA | GBA | `linkslot-pack-armgba-*.lsp` | 第三颗 GBA 核心；netpacket 联机（电缆/无线） |
| Nestopia | FC | `linkslot-pack-nestopia-*.lsp` | 高兼容 FC 核心，适合汉化/特殊 mapper 游戏 |
| supafaust | SFC | 自行放入 `System/linkSlot/cores/supafaust/`，或安装 `linkslot-pack-supafaust-*.lsp` | 因许可证与 GLIBC 兼容性原因不随包分发 |

- armGBA 的联机沿用 gpSP 的 carried 白名单；未验证游戏（例如马里奥赛车）会被拒绝，
  请改用 mGBA 电缆联机。armGBA 的 netpacket 协议按构建匹配，**两端需同一构建**。
- 只安装可信来源的核心：核心是原生代码，会以设备权限运行。

## 3. 安装、升级与扩展包

### 3.1 全新安装

1. **关机**，取出 SD 卡并备份：
   - `System/`（尤其是 `System/linkSlot/`）；
   - `linkSlot/Config/`；
   - `Saves/`、`States/`（如果你的卡上已有存档）。
2. 解压 `linkslot-v1.0.49-h700.zip`。
3. 把解压后**文件夹里的内容**合并到 SD 卡（SD2）根目录，替换同名文件；
   不要在卡里再套一层 `linkslot/` 目录。
4. 插卡开机，BaseOS 会通过 `System/launch_frontend.sh` 启动前端。

完成后卡根应有 `System/`、`Games/`、`Saves/`、`States/`、`Labels/`、
`Cheats/`、`Info/`、`Guides/`、`Overlay/`、`Wallpapers/`、`linkSlot/` 等目录。

**安装包会覆盖**：

- `System/**`（程序、核心、脚本、资源、许可证）；
- `README-ZH-CN.md`；
- `linkSlot/version.json`；
- `linkSlot/Config/README.txt`、`linkSlot/Config/theme.txt`；
- `linkSlot/mods/README.txt`、`Labels/README.txt`、`Overlay/README.txt`、
  `Wallpapers/README.txt`。

**安装包不会包含**（因此合并安装会保留）：

- ROM、存档、即时存档；
- `linkSlot/Config/` 下的个人配置：`config.toml`、`storages.toml`、`slot.state`、
  `language.txt`、`controls.txt`、`shortcuts.txt` 等；
- `Cheats/`、`Info/`、`Guides/`、`Labels/<平台>/`、`Overlay/<平台>/`、
  `Wallpapers/` 里的个人文件；
- `linkSlot/mods/<id>/`、`linkSlot/Logs/`、`linkSlot/Metadata/`、
  `linkSlot/Fronts/`、`linkSlot/Achievements/`。

> 版本包**不再内置金手指合集**。`Cheats/` 在包内是空目录；需要金手指时自行放入
> `.cht`（见 13.1），或通过 Web 游戏详情上传。

### 3.2 通过 Web 升级

1. 在设备上：**M → 网络 → 启动网络服务器**，记下地址；
2. 手机/电脑连同一 WiFi，打开该地址；
3. Web：**设置 → 维护 → 上传系统更新**，选择 `linkslot-v*.zip`，点
   **上传版本包**；
4. 回到设备：**M → 系统 → 安装更新**，按 A 确认；
5. 设备会自动重启并替换 `System/**` 与 `linkSlot/version.json`。

说明：

- 升级包必须带 `linkSlot/version.json`；网页只负责上传暂存，**不提供执行升级
  或重启的按钮**，安装必须在掌机上确认；
- 升级只替换系统程序，保留游戏、存档、配置与 mods；
- 正式包只接受高于当前版本的包，不能降级；本开发构建也允许同版本重装；
- 卡只读、设备在游戏中或同步中时会被拒绝；先回到主界面并修复/解除只读；
- 只上传可信来源的版本包。

### 3.3 LSP 扩展包

扩展包是 ZIP 容器（扩展名 `.lsp`），可给已发布的 linkSlot 增加可选核心或成就：

1. 下载 `linkslot-pack-<id>-v<version>.lsp`；
2. Web → **扩展** → **扩展包** → 选择文件 → **上传并安装**；
3. 安装后：
   - 核心包：重开对应卡带的核心选择器，多出一颗芯片；
   - 成就包：刷新 Web「成就」页或设备成就页，即可看到新增定义与徽章。

同一张卡片里可以**批量安装**多个 `.lsp`、按「核心包 / 成就包」筛选、随时卸载。
不需要解压或重启。

卸载核心包时：

- 卡带的 `selected_core` 记录保留；核心文件不在时启动会回退默认核心并提示一次，
  重新安装后恢复；
- `Saves/`、`States/`、`Cheats/` 下该核心的存档/状态/金手指不会被删除；
- 成就包不会包含解锁记录，卸载不会删除已解锁进度。

扩展包格式、`pack.json` 字段与打包命令见
[EXTENSION-PACKS-ZH-CN.md](EXTENSION-PACKS-ZH-CN.md)。

### 3.4 首次使用

1. **语言**：M → 系统 → 语言，选择中文或 English（Web 设置 → 通用 → 语言
   也可切换，两边共用同一文件）。
2. **WiFi**：M → 网络 → WiFi 连接，打开开关后扫描并连接；也可手动输入隐藏网络。
3. **时间**：联网后会自动 SNTP 校时；时区默认 `UTC+08:00`。如需强制用网络时间
   与时区覆盖本机设置，在 Web **设置 → 通用 → 时间同步**里打开
   「联网时强制同步时间和时区」。
4. **Web 管理**：M → 网络 → 启动网络服务器；关闭弹窗即停止服务。
5. **云同步**：Web → 云同步 → 添加 WebDAV；然后在设备 **网络 → 同步方式** 里
   测试并切换生效项。
6. **放游戏**：把 ROM 放进 `Games/<机种>/`。手动拷入后重启 App（或重新插卡）
   才会扫描到；Web 上传的游戏会立即出现在游戏库。
7. **可选**：安装扩展包、mod，或上传封面/介绍/攻略。

| `linkSlot/mods/<id>/` | mod 目录 |
| `linkSlot/Config/` | 设置与状态（见 4.3） |
| `linkSlot/Logs/` | 日志、崩溃记录 |
| `linkSlot/version.json` | 当前版本、构建、逐文件 SHA-256 |
| `System/linkSlot/bin/` | `linkslot`（前端）、`linkslot_sync`（云同步 CLI）、`fsck.exfat` |

| `System/linkSlot/shell/` | 卡内脚本 |

> 日志在 `linkSlot/Logs/`，不是卡根 `Logs/`。

### 4.2 命名与识别规则

- **游戏名 = ROM 文件名（不含扩展名）**。封面、介绍、视频、攻略、金手指、电池
  存档都按这个名称匹配。
- **ROM 身份 = 文件完整内容的 SHA-256**。云同步、卡带传输、查重都按内容判断；
  同名但内容不同是两张卡，改名但内容相同仍是同一张卡。
- 导入合集时，内容相同的 ROM 会跳过；Web「添加游戏」遇到同名或同内容会拒绝。
- 卡带元数据保存在 `linkSlot/Metadata/library.db`（WAL 模式）。备份或迁移时请同时
  保存 `library.db` 以及运行中的 `-wal` / `-shm` 文件。
- 在 Web 里重命名游戏时，会一起移动 `States/`、`Saves/`、`Labels/`、`Guides/`、
  `Cheats/` 和 `Fronts/` 下的关联文件，并更新最近游玩/收藏引用。
- 手动在电脑上改名不会搬动存档目录；请优先用 Web 重命名。

### 4.3 常用配置文件

`linkSlot/Config/` 由前端与 CLI 共同读写；删除某个文件会恢复该文件的默认值
（游戏与存档不受影响）。

| 文件 | 作用 |
|---|---|
| `slot.state` | 音量、亮度、遮罩、存档开关、按键布局、卡带架、传输内容等 |
| `config.toml` | 云同步主配置（WebDAV、设备 id、同步、WiFi） |
| `storages.toml` | 多个 WebDAV 同步方式，`active` 指向生效项 |
| `language.txt` | `zh-CN` / `en-US` |
| `controls.txt` | 游戏内按键重映射 |
| `shortcuts.txt` | 快捷键映射 |
| `carousel.txt` | 主界面「上一个/下一个卡带架」「收藏卡带」的键位 |
| `selected_core.txt` | 每个游戏选定的核心 |
| `core_tray.txt` | GBA 备用核心记忆 |
| `video_mode.txt` | 每个游戏的拉伸/原始比例 |
| `theme.txt` | 主题预设与可选的手工颜色 |
| `cart_color.txt` | 卡带颜色覆盖 |
| `cart_shell.txt` | 卡带外壳样式覆盖 |
| `wifi_saved.toml` | 已保存 WiFi 列表 |
| `web.toml` | Web 单文件上传上限（默认 32 MB，1–256 MB） |
| `log_level.txt` | `error` / `warn` / `info` / `debug` |
| `device_name.txt` | 联机显示名（最多 16 字节） |
| `clock.toml` | 时区是否手动、是否强制联网校时 |
| `link_band.txt` | 热点频段（5GHz / 2.4GHz） |
| `rom_sha256.tsv` | 开机后台维护的 ROM 哈希索引 |
| `last-run.txt` | 运行标记；残留表示上次异常退出 |
| `mod_permissions.toml` | mod 能力授权 |
| `packs/installed.json` | 扩展包安装记录 |
| `cache/`、`work/`、`upgrade/` | 同步缓存、临时工作区、升级暂存 |

## 5. 主界面

### 5.1 卡带架与按键

卡带架顺序为：**最近游玩 → 收藏 → GBA → GB → GBC → FC → SFC → MD**。
空卡带架会自动跳过；上次所在的架与选中的卡带会记住（`slot.state` 的
`shelf` / `shelf_cart`）。

| 按键 | 作用 |
|---|---|
| ← / → | 选择卡带（长按可连续移动） |
| ↑ / ↓ | 按首字母跳组 |
| A | 插入卡带并启动 |
| **长按 A 约 0.5 秒** | 从游戏开头启动（忽略自动读档） |
| **长按 B 约 0.8 秒** | 打开游戏介绍/详情页 |
| X | 搜索（拼音 / 中文 / 英文） |
| Y（按下） | 开始云同步长按计时（短按无功能） |
| **长按 Y 约 1.5 秒** | 云同步当前卡带；有手动 mod 时先弹出选择卡 |
| START | 打开核心选择器（PCB 板） |
| L1 / R1 | 上一个 / 下一个卡带架（可在「主界面按键」里改绑） |
| L2 | 直接跳到「收藏」架 |
| R2 | 收藏 / 取消收藏当前卡带（可改绑） |
| **按住 SELECT 约 1 秒** | 进入 / 退出文件夹模式 |
| SELECT + START | 卡只读时进入「修复存储卡」 |
| M | 打开设置菜单 |
| 电源短按 / 长按约 1 秒 | 休眠·唤醒 / 电源菜单 |

底部会显示当前可用按键提示；进入传输模式、文件夹模式或同步时会换用对应提示。

### 5.2 搜索（X）

- 支持完整拼音（`baokemeng`）、首字母（`bkm`）、英文或数字游戏名；
- 候选来自当前所有平台的游戏库；上下方向键翻页，←/→ 选择候选，A 选字；
- **SELECT 切换候选焦点**，再按 SELECT 或 B 返回键盘；
- START 执行搜索，X 关闭搜索；
- 结果页显示平台标签，A 跳转到对应卡带架，B 返回搜索，X 关闭；
- 文件夹模式下只搜索当前文件夹。

### 5.3 文件夹模式（按住 SELECT 约 1 秒）

- 按 ROM 真正所在的子目录浏览，只列出有 ROM 的真实文件夹；
- L1 / R1 切换文件夹组；
- X 搜索当前文件夹；
- 再按住 SELECT 约 1 秒退出；
- 进入的目录会记在 `slot.state` 的 `folder_mode` / `folder_path`；
- 在「收藏」「最近游玩」里也能按住 SELECT 进入，借所选卡带的机种跳到对应目录；
- 整张卡都没有子目录时会提示「没有可浏览的文件夹」。

### 5.4 游戏介绍 / 详情页（长按 B 约 0.8 秒）

页面内容：

- 卡带封面、标题、介绍文字（`Info/<平台>/<游戏名>.txt`，最多显示约 4000 字）；
- 游玩统计（已玩次数、最近游玩时间）；
- 演示视频（`Info/<平台>/<游戏名>.mp4`）；
- 成就摘要（本游戏已解锁 / 总数 / 分数）。

页内按键：

| 按键 | 作用 |
|---|---|
| ↑ / ↓ | 滚动介绍文字 |
| Y | 查看本游戏成就 |
| X | 删除卡带（会二次确认，默认停在「取消」） |
| B / M | 关闭 |

删除卡带会移除 ROM、封面、介绍、视频和数据库元数据，**保留** `Saves/`、
`States/` 里的存档与进度。卡只读时拒绝删除。

### 5.5 核心选择（START）

见 2.3。打开后：

- ←/→ 选择芯片或托盘；
- A 应用；在 GBA 托盘上 A 与第 2 槽互换；
- **X** 打开卡带前盖托盘；
- **Y** 打开云同步芯片选择器（等同于长按 Y 的选择卡）；
- B 返回。

### 5.6 前盖托盘（核心选择页按 X）

- 第 0 项永远是「默认外壳」；
- 之后是最多 5 张自定义前盖；←/→ 选择，A 应用，B 或 X 关闭；
- 没有自定义前盖时提示「请先在网页端添加前盖」；
- 前盖编辑器在 Web 游戏详情里（见 12.2）。

### 5.7 收藏、最近游玩与背景

- R2 收藏 / 取消收藏，提示「已收藏 / 已取消收藏」；
- 选中的收藏卡带在标签右上角显示金色星星；
- L2 直接跳到「收藏」架；
- 最近游玩最多保留 10 条，按最后启动排序；需要在「主界面 → 外观与显示」里打开
  「显示最近游玩」；
- 普通卡带浏览时，当前选中的卡带上方会显示「游戏时长 X 小时 Y 分」；
  核心选择器、搜索、游戏菜单、同步覆盖层显示时隐藏；
- 壁纸从 `Wallpapers/` 轮换；Web 设置 → 通用 → 机种背景图可为每个机种上传
  独立背景（重启后生效），优先于壁纸。

### 6.2 画面

- **屏幕与亮度**：亮度 0–9（默认 5）、蓝光 0–9（默认 0）。
- **画面效果**：
  - GBA 着色器：关闭 / LCD3x / 网格 / 点阵 / 四级 LCD；
  - GB / GBC 着色器：关闭 / 网格 / 纸感 / 四级 LCD；
  - GB / GBC 调色板：关闭（自动）或 48 个内置调色板；
  - 色彩校正（全机种）：按核心提供开关。
- **遮罩**：FC / GB / GBC / SFC 四行，各自左右选择「无」或对应目录下的
  `Overlay/<机种>/*.png`。要求 720×480、带透明通道，游戏画面从 alpha < 0.5
  的区域透出。GBA 不支持遮罩。选择写入 `slot.state`。
- **主题**：默认深色 / 网络青 / 复古暖色。选择后立即写 `theme.txt`，提示
  「主题已保存，重启后生效」。内置主题只改颜色，不改布局、字体、封面和壁纸；
  第三方主题包可以额外提供壁纸与字体（见 12.6）。

### 6.3 主界面

- **外观与显示**：
  - 游戏标题：显示 / 隐藏卡带标题；
  - 无封面用存档图：没有封面时用最近即时存档缩略图兜底；
  - 显示最近游玩：是否显示「最近游玩」卡带架。
- **主界面按键**：上一个卡带架 / 下一个卡带架 / 收藏卡带，三行可左右改绑；
  默认 L1 / R1 / R2，写入 `carousel.txt`。

### 6.4 游戏

- **快进**：关闭 / 2× / 3× / 4× / 6×（默认 6×）。快进期间也会记录倒带快照，
  快进后倒带会从附近往回走，不会一步跳回起点。
- **快进声音**：快进时是否保留声音。
- **倒带**：开启 / 关闭（默认开启）。
- **震动**：开启 / 关闭（默认开启）。
- **存档设置**：
  - 全局默认：「默认插入时加载」「默认退出时保存」（默认都开）；
  - GBA / GB / GBC 各自有「插入时加载」「自动保存」两行，三态为
    **默认 / 开启 / 关闭**，左右循环；
  - FC / SFC / MD 没有独立三态行，始终跟随全局默认；
  - 关闭自动保存后，退卡、自动保存、合盖、关机前都不再写该平台的
    `resume.state`；电池存档 `.sav` 仍照常保存；
  - 关闭保存不会删除已有的 `resume.state`；「不自动写」不等于「删档」。

### 6.5 按键与快捷键

- **快捷键一览**：静态帮助页，列出当前生效的快捷键与各机种差异。
- **快捷键映射**：14 行 = 13 个快捷键 + 最后一行「重置快捷键」。
  - 按 A 进入捕获：「按下一个按键」；按住 SELECT 再按 = 组合键；按 M 结束；
  - 按下的键已被别的快捷键占用时提示「按键重复，请检查」，不会覆盖；
  - 什么都没按就按 M 会问「设为无？」：A 设为「无」，B 取消；
  - 左右键仍可循环切换（无 → SEL+键 → MENU+键 → 单键）；
  - 最后一行「重置快捷键」按 A 恢复全部默认；
  - 修改立即写入 `shortcuts.txt`，Session 下一帧热重载，不需要重启。
- **按键映射**：13 行游戏按键（上/下/左/右/A/B/Select/Start/L/R/连发 A/连发 B/
  肩键布局）。肩键布局有：关闭 / 交换 R1L1 和 R2L2 / XY 替代 LR / 同时启用。
- **SFC / MD 的 X / Y**：不在 13 行里，它们是正式按键；需要换位时直接改
  `controls.txt` 的 `x=` / `y=` 两行（例如 `x=y`、`y=x`）。该文件所有机种共用，
  改后对所有机种生效。
- **连发按键（GBA）**：开 / 关，默认关闭。X / Y 在 FC、GB、GBC、GBA 上可作为
  连发 A/B；SFC 的 X/Y 是正式按键；MD 使用六键手柄。选择「XY 替代 LR」时会自动
  关闭连发。

### 6.6 网络

| 行 | 说明 |
|---|---|
| WiFi 连接 | 开关、扫描、已保存网络、隐藏网络、密码键盘、自动关闭 WiFi |
| 启动网络服务器 | 启动内置 Web 管理页，显示访问地址 |
| 同步方式 | 列出 Web 上配置的 WebDAV，A 测试、X 切换生效项 |
| 云同步内容 | 全部 / 仅即时存档 / 仅电池存档，限制长按 Y 同步的单元 |
| 卡带传输模式 | 打开卡带传输房间菜单（见 9） |
| 热点频段 | 5GHz 优先 / 2.4GHz 兼容；两端必须同档，切换后新建联机生效 |

**WiFi 连接**细节：

- 打开页面后先读实际状态；WiFi 开关关闭时不扫描，打开后开始扫描，Y 刷新；
- 已连接过的网络会出现在扫描结果前的「已保存」列表，选中后直接使用保存的密码；
- 加密网络弹出屏幕键盘：A 输入、B 删除、Y 切换大小写/数字符号、START 确定、
  X 取消；
- 也可「手动输入网络名称」连接隐藏网络；
- 连接成功后凭据写入 `config.toml` 的 `[wifi]`，并同步到 `wifi_saved.toml`；
- 对已保存网络关联失败时，可按 X 重新输入密码；
- 「自动关闭 WiFi」可选 1 / 3 / 5 / 10 / 30 / 60 / 120 分钟 / 永不，默认 10 分钟；
  WiFi 设置页、Web 服务、云同步、扫描/连接、联机菜单与联机会话期间不会自动关闭；
- 设备键盘只支持 ASCII；SSID 含中文时请在 Web 网络页保存；
- 状态栏 WiFi 图标只表示 `wlan0` 有载波且取得 IPv4，不表示云端 WebDAV 可达。

### 6.7 系统

- **日期与时间**：设置日期、时间和时区（UTC−720 到 UTC+840，默认 +480）；
  联网后自动 SNTP 校时。详见 16.1。
- **语言**：中文 / English，立即生效并写 `language.txt`；写入失败时提示
  「仅本次生效」。
- **合盖自动关机**：3 / 10 / 30 分钟 / 永不，默认 3 分钟；合盖休眠后达到该时间
  保存并关机；「永不」只取消休眠超时关机，不取消低电量保护。
- **mod 管理**：列出已安装 mod；上下选择，A 启用/停用，左右调优先级，B 返回。
- **安装更新**：确认安装 Web 上传的版本包；A 开始安装并重启，B 返回。
- **关于**：当前版本、构建日期、本机名称、作者、原项目与感谢名单；
  短按 A 查看感谢名单，长按 A 约 1 秒把日志级别设为调试。

## 7. 游戏内

### 7.1 游戏菜单（游戏中按 M）

一页 7 项：

| 项 | 作用 |
|---|---|
| 即时存档相册 | 查看 / 读取 / 删除即时存档 |
| 金手指 | 开关当前 ROM 的金手指条目 |
| 查看攻略 | 打开 TXT / EPUB 攻略 |
| 联机 | 进入联机页面（等同 SELECT + M） |
| 快捷键一览 | 只列游戏内相关项，显示当前映射 |
| 重新开始游戏 | 先保存，再原地重启核心，从头开始本卡（不退卡、不读回自动存档） |
| 退出游戏 | 先保存，再退卡回主界面 |

上下选择、A 确认、B / M 返回。

- **长按 M 约 1 秒**：屏幕底部出现「继续按住 · 退出游戏」进度条，按满 1 秒即
  存盘退卡；松手取消。普通点按不会出现该提示。
- **长按 A 约 0.5 秒**（在主界面选卡时）：从游戏开头启动，忽略自动读档。

### 7.2 即时存档相册

- 每个游戏最多保留 10 个即时存档（环形缓冲）；
- 目录 `States/<机种>/<核心>/<游戏名>/`，时间戳 `.state` 加同名 `.png` 缩略图；
- 相册按键：←/→ 翻动、A 读取、Y 删除、**X 撤销删除（30 秒内）**、B / M 关闭；
- 没有存档时显示「暂无即时存档」。

### 7.3 金手指

- 默认路径 `Cheats/<平台>/<核心>/<游戏名>.cht`；也可通过 Web 游戏详情设置其他
  路径或直接上传 `.cht`。
- 游戏内：M → 金手指；上下选择、A 开关、左右翻页、B 返回。
- 所有条目默认关闭，重新进入游戏后需重新开启。
- gpSP 同时最多开启 20 项、每项最多 64 行；超出或不支持的条目不会出现在 gpSP
  可读文件中，mGBA 会保留可解析的部分。
- 进入联机前会自动关闭全部金手指并提示；联机中不可使用。
- 关闭金手指会停止继续写入，但不会撤销已经获得的金钱、道具等效果。
- 不同地区、汉化版或改版可能使用不同地址；同名配对不等于每条代码均有效。

### 7.4 攻略

- 路径：`Guides/<平台>/<游戏名>.txt` 或 `.epub`；也可在 Web 游戏详情里指定其他
  路径或上传。
- TXT 自动识别 UTF-8 与常见 GBK 中文；EPUB 按 spine 顺序提取正文和图片，
  图片单独成页并等比缩放，脚本与样式忽略。
- 阅读页：上下逐行滚动（按住连滚）、L / R 翻一屏、Start 回到开头、B 返回；
  右侧滚动条显示进度，并记住阅读位置。
- 没有攻略时提示「暂无攻略」，可在 Web 上传或由 mod 生成。

### 7.5 存读档、快进、倒带与画面

| 操作 | 默认键 |
|---|---|
| 保存即时存档 | SELECT + R1 |
| 读取最新即时存档 | SELECT + L1 |
| 按住快进 | R2（双击可锁定，再按解除） |
| 按住倒带 | L2（需开启倒带） |
| 提高 / 降低亮度 | SELECT + ↑ / ↓ |
| 降低 / 提高蓝光 | SELECT + ← / → |
| 切换色彩校正 | SELECT + Y |
| 上一个 / 下一个调色板 | SELECT + L2 / R2 |
| 下一个 / 上一个着色器 | SELECT + A / B |
| 切换静音 | SELECT + 音量加或减 |

各机种画面切换不同：

- **FC / GB / GBC**：裸 L1 = 拉伸铺满，R1 = 原始比例；
- **SFC / MD**：裸 L1/R1 属于游戏按键（MD 的 L1/R1 对应六键的 X/Z）；画面切换
  改为 **SELECT + L2 / R2**（L2 铺满高度、R2 原始比例），
  **SELECT + L1 / R1** 仍保留为即时读/存档；
- **GBA**：L/R 属于游戏，没有画面切换键，只受着色器影响。

组合键窗口约 0.6 秒：按住 SELECT，再在 0.6 秒内按另一个键。

### 7.6 重新开始与退出

- **重新开始游戏**：先写电池存档与恢复存档，然后在当前页面直接重启核心，从头
  开始这张卡；不退卡插卡，也不读回自动存档。
- **退出游戏**：先写电池存档与恢复存档，再播放拔卡动画回到主界面；长按 M 与
  菜单里的「退出游戏」走同一路径。
- 两项都会先保存，所以误按也能从即时存档相册读回刚才的进度。

## 8. 联机

### 8.1 支持情况

| 机种 / 核心 | 传输 | 说明 |
|---|---|---|
| GBA + mGBA | 电缆 | 只支持电缆；不会提供「无线」切换 |
| GBA + gpSP | netpacket 无线 | 只接受白名单内已验证的卡带；不传主机进度 |
| GBA + armGBA | netpacket 电缆/无线 | 沿用 gpSP 白名单；两端需同一构建；不传主机进度 |
| GB / GBC + mGBA | 电缆 | 以核心与游戏支持为准 |
| FC / SFC / MD | 单机双人 | 一台主机两台手柄；主机 = 1P，副机 = 2P；可传主机进度与存档 |

- GBA 联机使用专用热点；FC / SFC / MD 可在「专用热点」与「同一 Wi-Fi」之间用
  SELECT 切换。
- 热点 SSID 为 `slotlink`，联机端口 7211。同一 Wi-Fi 模式下两台掌机需连同一个
  路由器，且未联网时会先提示去连接。
- 双方必须使用**同一机种、同一核心、同一 ROM 内容（SHA-256）**；不一致会提示
  「对方的游戏不一致」或「核心不一致」。
- gpSP / armGBA 的白名单来自 gpSP 的 carried 列表。马里奥赛车（`AMKE`）等电缆
  游戏请用 mGBA 并在两端保持在 Cable；armGBA 的协议按构建匹配，两端需同一构建。

### 8.2 操作

1. 两台掌机各插同一张卡（或进入同一游戏）；
2. 一台在游戏中按 **SELECT + M**（或菜单「联机」）选「创建联机」；
3. 另一台选「加入联机」；
4. 主机先等待，副机加入后建立连接；
5. 主机可以把当前游戏与存档状态交给副机（gpSP / armGBA 不传进度，两端各自
   进入游戏）。

联机页面会显示：主机 / 副机、对方名称、双方游戏、连接状态，以及「断开联机」
「开始联机」「返回」等操作。结束联机需要二次确认。

### 8.3 房间与掉线

- 主机创建一次后保持主机状态；副机没来或中途掉线，主机会继续等待；
- 副机随时重新加入；主机仍在当前游戏即可恢复；
- 主机主动离开当前游戏（退卡、回主界面、关机、休眠等）才会结束房间；
- 断线宽限约 2 秒；网络恢复后提示「联机已恢复」；
- 主机换游戏时，副机会收到「加入主机游戏《…》？」询问，10 秒无回答视为拒绝；
- 联机中不能云同步、不能修改 mod、不能使用金手指；电源菜单会被拒绝。

### 8.4 限制

- 不支持 4 人分插器、光枪等外设；
- 不支持 `.fds`；
- mGBA 不提供无线模式；gpSP / armGBA 不支持未验证卡带；
- 两端版本差异过大可能无法互通；建议双方使用同一版本。

## 9. 卡带传输模式

卡带传输用于在两台掌机之间搬一张完整的卡带（含封面、介绍、视频、外壳配色），
或只搬存档；它不运行游戏，和「联机」是两件事。

### 9.1 入口与匹配

**M → 网络 → 卡带传输模式**。三行：

- **创建匹配**：本机开房，等待另一台；
- **加入匹配**：搜索同一网络下的主机；
- **返回**：回到主界面。

按键：↑/↓ 选择，A 执行，**SELECT 切换「专用热点 / 同一 Wi-Fi」**，B 返回。
传输房间显示「主机 / 副机」与当前所选卡带。

### 9.2 传输内容

在传输房间按 **Y** 打开「传输内容」：

| 选项 | 包含 |
|---|---|
| 仅卡带（默认） | ROM、封面、介绍、视频、外壳配色；不含存档 |
| 仅存档 | 电池存档 `.sav`、续玩状态 `resume.state`、进度缩略图 `resume.png` |
| 卡带＋存档 | 以上全部；覆盖对方存档前会先备份 |

选择写进 `slot.state` 的 `transfer_content`，重启后保留；房间标题的内容徽章会一直
显示这次会发什么。已经发出的报价不能再改。

### 9.3 传输过程

1. 一方选中卡带按 A 发出传输请求；
2. 另一方收到「接收这张卡？」确认；
3. 接收方在卡带真正落盘前显示同平台、同壳色的空白预览卡，带游戏标题；
4. 卡带插入后保持，界面显示一张米色「传输清单」：
   - 本机/对方角色、发送/接收方向、游戏名；
   - 真实百分比与字节；卡带与存档分两列；
   - 已完成项打勾，当前项带行内小进度，未到项空框；
   - 等待对方确认时显示「等待对方确认…」和虚线槽，不显示 0%；
5. 完成后清单全勾并在右上角盖红章，然后弹出卡带；
6. 接收方得到完整卡带后会自动切到新卡所在平台页并选中它。

### 9.4 重复与资料补全

- 接收方按 ROM 内容哈希判断是否已有同一张卡；不会遍历整个卡带库。
- 对方已有同一 ROM：
  - 封面、介绍、视频本地都有：不开始传输，发送端卡带先插入、停 1 秒再弹出，
    提示「对方已拥有当前卡带」；
  - 本机缺少部分资料：询问「补充『游戏名』的内容？」，确认后只补缺失的
    封面/介绍/视频，不重传 ROM，也不覆盖本地已有资料；
- 同名卡已存在时自动使用「名字 (2)」等新名字，不覆盖旧卡；
- 接收方替换任何已有存档/状态/缩略图前，先把旧文件复制为
  `*.conflict.<时间戳>.*`，日志会写明备份位置。

### 9.5 退出与版本兼容

- 传输中按 M 会确认是否退出传输模式；
- 传输模式与游戏联机互不影响；退出传输模式会关闭热点/匹配；
- 「传输内容」和「核心」是 v1.0.43 起的新字段：旧版本读到多余尾部会当作
  「仅卡带」，旧版本发来的报价也按「仅卡带」接收；
- 只同步存档要求接收方已有同一张卡；没有时直接拒绝并提示
  「本机没有这张卡，无法只同步存档」。

## 10. 云同步

### 10.1 配置

推荐在 Web 完成：**云同步** 页。

- 可保存多个 WebDAV，同一时间只有一个「当前生效」；
- 点选某个同步方式会立即切换并保存；
- 表单字段：名称、服务器地址、远程根目录、用户名、密码、自签 CA 证书、
  跳过 TLS 证书校验（仅调试）、保留云端旧文件（`keep_remote`）、清除密码；
- **测试连接使用当前输入框**，不需要先保存；会同时验证 DNS/TCP/TLS、用户名密码
  和远程根目录；
- 密码留空表示保留已保存的密码；环境变量 `LINKSLOT_WEBDAV_PASSWORD` 优先；
- 至少保留一个同步方式。

也可以直接编辑 `linkSlot/Config/config.toml`：

```toml
[webdav]
url = "https://nas.example.com/dav"
remote_root = "/linkSlot"
username = "rg34xx"
password = ""
ca_cert = ""
insecure = false

[device]
id = ""

[sync]
timeout_secs = 20
retries = 2
keep_remote = false

[wifi]
manage = true
ssid = ""
psk = ""
auto_off_minutes = 10
timeout_secs = 30
```

多 WebDAV 保存在 `linkSlot/Config/storages.toml`，`active` 指向生效项；生效项会
镜像回 `[webdav]`，旧配置仍可继续使用。

### 10.2 设备端同步

1. 在主界面选中卡带；
2. **长按 Y 约 1.5 秒**后松手；
3. 如果有启用的手动 mod，先弹出芯片选择卡片：
   - 内置「同步云存档」；
   - 每个启用的手动 mod 一张卡；
   - ←/→ 选择，A 开始，B 关闭；
   - 没有手动 mod 时直接进入云同步，不弹选择页；
4. 同步动画：网络 → 云端 → 连接 → 传输 → 校验 → 完成；
5. 云端较新时自动拉取，本地较新时自动推送，一致时提示「已是最新」；
6. 同步中按 B 可取消；超过 120 秒自动取消；联机中、只读卡、网页同步进行中
   都不能开始同步。

同步内容受 **网络 → 云同步内容** 限制：全部 / 仅即时存档 / 仅电池存档。

### 10.3 同步内容与云端结构

每个游戏有两个同步单元：

- **即时存档**：`States/<平台>/<核心>/<游戏>/` 下的 `resume.state`、时间戳
  `.state` 与对应 `.png` 缩略图；
- **电池存档**：`Saves/<平台>/<游戏>.sav`（兼容 `.srm`），云端固定命名为
  `battery.sav`。

云端以 **ROM 全文件 SHA-256** 为身份，不再按游戏名建目录：

```text
<remote_root>/
├─ layout.json
├─ achievements.json
└─ <平台>/<ROM SHA-256>/
   ├─ playtime.json
   ├─ achievements.json
   ├─ state/<核心>/
   │  ├─ meta.json
   │  ├─ resume.state
   │  ├─ resume.png
   │  └─ <YYYY-MM-DD_HH-MM-SS>.state / .png
   └─ sav/
      ├─ meta.json
      └─ battery.sav
```

- `meta.json` 记录单元类型、平台、ROM SHA-256、版本、设备、文件表与聚合哈希；
  `meta.json` 最后提交，失败不会破坏旧版本；
- 每游戏的 `playtime.json` 与每游戏成就 `achievements.json` 位于游戏级，不参与
  存档冲突；全局成就在云端根 `achievements.json`；
- 旧版按「平台/核心/游戏名」建立的云端目录**不会自动读取、移动或迁移**。

### 10.4 冲突、备份与差量

- 普通 `sync` 发现冲突时不会覆盖：设备上显示冲突页，分页为
  全部 / 即时存档 / 电池存档；
- ←/→ 切页，↑/↓ 选方向「覆盖本地 / 覆盖云端」，A 确认该页，B 放弃剩余单元；
- 覆盖前自动备份被覆盖方：
  - 本地即时存档 → `States/<平台>/<核心>/<游戏>.conflict.<时间戳>/`；
  - 本地电池存档 → `Saves/<平台>/<游戏>.conflict.<时间戳>.sav`；
  - 云端旧版本 → `<unit>/.conflict.<时间戳>/`（仅在强制上传时）；
- 只传输与云端 `meta.json` 记录不一致的文件；未变化文件不重传；
- `--full` 修复：手动 CLI 可强制整单元重传/重下，用于修复被其他工具改坏的
  本地或云端文件；`sync --full` 只在判定需要传输时忽略差量；
- 云端被其他设备更新时，CLI 会返回 `changed-since`，UI 提示重新选择方向。

### 10.5 改名与旧数据

- 云端身份是 `平台 + ROM SHA-256`，游戏名只影响本地目录和显示；
- ROM 改名后，第一次同步会按新名字从云端拉回存档；旧名字的本地目录不会被
  自动搬迁，也不会自动删除；
- 不同内容但同名的 ROM 会得到不同 SHA-256，互不覆盖；
- 手动 CLI 用 `--game` 自动找 ROM 时，如果有多个同名 ROM 会报错，请用 `--rom`
  指定；
- 旧版按游戏名的云端目录不会被新客户端读取；需要时可在电脑上计算 ROM 的
  SHA-256，把旧目录改名为该哈希。

### 10.6 命令行

卡内 CLI 位于 `System/linkSlot/bin/linkslot_sync`，用法里的命令名显示为
`linkSlot`；在卡上请通过 `sh System/linkSlot/shell/linkslot.sh <参数>` 调用。
设备端长按 Y 使用的就是 `sync`。

```text
linkSlot sync   --platform GBA --emulator mgba --game <游戏名> [--rom <ROM 路径>]
                [--only state|sav] [--resolve upload|download]
                [--expect state=12,sav=7] [--full] [--net-up] [--timeout 30] [--verbose]
linkSlot push   --platform GBA --emulator mgba --game <游戏名> [--rom <ROM 路径>]
                [--force] [--full] [--net-up] [--timeout 30] [--verbose]
linkSlot pull   --platform GBA --emulator mgba --game <游戏名> [--rom <ROM 路径>]
                [--force] [--full] [--net-up] [--timeout 30] [--verbose]
linkSlot status --platform GBA --emulator mgba --game <游戏名> [--rom <ROM 路径>]
linkSlot net status | net test | net up [--timeout 30]
linkSlot config init [--force]
linkSlot mods list [--json] | mods check --id <id> [--action <id>]
linkSlot mods test --profile <同步方式 id>
linkSlot mods run --platform ... --game ... [--id <mod> [--action <id>]]
linkSlot mods boot --id <mod> --action <action>
linkSlot achievements status [--json] | achievements sync
```

常用参数：

- `--platform`：`GBA` / `GB` / `GBC` / `FC` / `SFC` / `MD`（大小写敏感）；
- `--emulator`：核心 id（`mgba`、`gpsp`、`fceumm`、`snes9x`、`genesis_plus_gx`、
  `nestopia`、`supafaust`、`armgba`），必须与平台配对；
- `--game`：本地 `States/<平台>/<核心>/<游戏名>` 目录名；
- `--rom`：显式指定 ROM；省略时在 `Games/<平台>/` 下递归查找唯一同名 ROM；
- `--only`：`state` 或 `sav`，只处理指定单元；
- `--resolve`：冲突时强制覆盖方向；也可按单元写
  `state=upload,sav=download`；
- `--force`：`push` / `pull` 强制覆盖（先备份）；
- `--full`：忽略「已是最新」，整单元重传/重下；
- `--net-up`：网络不可用时强制按需联网；
- `--verbose`：详细步骤写到 stderr，并写入日志。

**注意**：`push` / `pull` 目前只处理即时存档（state）；要同步电池存档，请用
`sync`（可配合 `--only sav`），或使用设备长按 Y / Web 的同步。

退出码：

| 码 | 含义 |
|---|---|
| 0 | 成功或无更新 |
| 1 | 网络 / WebDAV / TLS / 时钟 / 服务器 / 超时 |
| 2 | 冲突（未带 `--resolve`） |
| 3 | 配置错误 |
| 4 | 本地文件、校验或忙碌 |

`sync` 两个单元一个成功一个失败时结果为 `partial`，退出码取失败类别。
stdout 会输出 `LINKSLOT_ACTION`、`LINKSLOT_RESULT`、`LINKSLOT_DIRECTION`、
`LINKSLOT_STAGE` 等契约行；人类可读文本在 stderr。

### 10.7 限制与日志

- 同步即时存档与电池存档（以及游戏时长、成就），不后台自动同步；联机进行中不能同步；
- 同步期间不要关机/重启；合盖、电源菜单、联机都会中止同步；
- 首次使用前请先在 Web 配置 WebDAV，并在设备「网络 → 同步方式」测试通过；
- 日志：`linkSlot/Logs/linkSlot.log`；日志级别在 `linkSlot/Config/log_level.txt`，
  Web **设置 → 维护 → 服务日志**也可切换（错误/警告/信息/调试，切换即保存）；
- 调试级别会记录 WiFi 扫描、关联、DHCP 等细节，日志增长较快，排查后切回信息。

## 11. 成就

### 11.1 三类成就

1. **全局成就（15 个）**：初次启动、游玩 1/10/100 小时、启动 10/100 次、
   玩过 3/5/10 个游戏、收藏 10/50/100 张卡、初次存档、存档收藏家、全平台收集。
   解锁记录在 `linkSlot/Achievements/unlocks.json`，成功同步时合并到云端
   `achievements.json`。
2. **每个 ROM 的通用成就（5 个）**：本作首次启动、本作 1 小时、本作 5 小时、
   启动 10 次、启动 30 次。与 RA 成就共用同一份每游戏解锁文件。
3. **RetroAchievements 扩展包成就**：通过 `.lsp` 成就包安装，定义在
   `linkSlot/Achievements/defs/<平台>/`，徽章在
   `linkSlot/Achievements/badges/<平台>/<SHA-256>/`。

### 11.2 设备端

- 入口：主界面长按 B 打开游戏介绍页，按 **Y** 查看本游戏成就；
- 页面合并显示 5 个通用成就 + 该游戏已安装的 RA 成就；
- 每行显示 √/·、标题、分数、40px 徽章、描述；RA 成就可显示 rcheevos 进度；
- 每页 5 行，↑/↓ 选择，A 查看详情，B 返回；
- 解锁通知带 44×44 徽章，完整显示 5 秒，仅 SELECT 可提前关闭；多个成就会排队；
- 全局成就解锁时也会弹通知，并随云同步到其他设备；
- 从云端补进的成就会提示「云端成就」。

### 11.3 Web 端

- **游戏库 → 成就**（不是顶级导航）；
- **通用成就** tab：5 个内置成就的聚合统计，显示覆盖游戏数、总分、每项成就下
  激活的游戏，可展开全部；
- **扩展包成就** tab：按游戏筛选、搜索、显示已解锁/总数、分数、进度条、解锁时间；
- 徽章分别来自 `/api/achievements/public/badge` 和
  `/api/achievements/badge`；
- 成就页只读，不提供解锁或重置入口。

### 11.4 同步与限制

- 每游戏成就按 ROM SHA-256 保存，改名不会丢进度；
- 云同步成功后做并集合并：id 只增不减，解锁时间取最早，最多重试 3 轮；
- 成就同步失败只记警告，不影响存档同步；
- 成就包不包含解锁记录，重装不会覆盖已有进度。

## 12. 外观、封面与资源

### 12.1 标签 / 封面

- 路径：`Labels/<平台>/<游戏名>.png`；
- 建议尺寸：GBA 1280×661；GB / GBC 1024×901；FC 1024×670；
- 其他尺寸会按比例缩放并从中心裁切；
- 没有封面时，可在「主界面 → 外观与显示」打开「无封面用存档图」，
  用最新即时存档缩略图兜底；
- Web 游戏详情里可替换封面。

### 12.2 前盖

- 每个游戏最多 5 张前盖，数据在 `linkSlot/Fronts/<平台>/<游戏名>/`；
- Web 游戏详情 → 外观 → 前盖：
  - **快速前盖**：用当前封面创建、上传图片生成、批量添加；可选完整显示/填满标签；
  - **新建前盖**：从空外壳打开图层编辑器，可加图片、文字、矩形、圆形、线条、
    渐变、标题/边框模板，支持缩放、拉伸、撤销/重做、全屏；
  - 可复制、导出/导入工程、删除；
- 设备端：主界面 START → PCB 板 → **X** 打开前盖托盘，←/→ 选择，A 应用；
- Web 游戏详情可切换 FC 机种的卡带模型（FC 卡带 / NES 卡带）；前盖有适用模型，
  选择时会按当前模型过滤。

### 12.3 卡带颜色与外壳

- Web 游戏详情「外观」→ 卡带颜色：取色器或 `#rrggbb`，保存后立即写入；
- 首次扫描到没有颜色的 ROM 时会分配稳定的随机初始色，写入
  `linkSlot/Config/cart_color.txt`；
- `linkSlot/Config/cart_shell.txt` 可手工设置外壳：

```text
Metroid Fusion = auto 6a3fa0 solid
```

  - Outline：`auto` / `notched` / `rounded`
  - Colour：十六进制 RGB
  - Finish：`solid` / `clear` / `glitter`

### 12.4 收藏金星与槽内铭牌

- 被收藏的卡带在标签右上角内侧显示金色星星；
- 卡槽底部默认使用内置的大字号蚀刻字标：最近游玩 / 收藏 / GBA / GB / GBC /
  FC / SFC / MD；
- 想替换时，把 380×44、透明底的 PNG 放到
  `System/linkSlot/assets/carts/`，文件名：
  `slot_back_recents.png`、`slot_back_favorites.png`、`slot_back_gba.png`、
  `slot_back_gb.png`、`slot_back_gbc.png`、`slot_back_fc.png`、
  `slot_back_sfc.png`、`slot_back_md.png`；
- 图片会按比例放进插卡口并裁成插卡口形状；主题包也可以提供同名铭牌。

### 12.5 屏幕遮罩

- `M → 画面 → 遮罩`，四行分别给 FC / GB / GBC / SFC 选择；
- 文件放在 `Overlay/FC/`、`Overlay/GB/`、`Overlay/GBC/`、`Overlay/SFC/`；
- 要求 720×480 PNG、带透明通道；透明区域（alpha < 0.5）显示游戏画面；
- 每行可选「无」或该目录下任意 PNG，文件名直接显示在菜单行；
- 四个机种独立选择，保存在 `slot.state` 的 `fc_mask` / `gb_mask` / `gbc_mask` /
  `sfc_mask`；
- GBA 不支持屏幕遮罩；着色器与调色板不受影响。

### 12.6 壁纸、背景图与开机图

- 壁纸：`Wallpapers/*.png`，H700 建议 720×480；开机时按 `wallpaper.deck` 轮换，
  其他尺寸等比缩放居中裁切；
- 机种背景图：Web → 设置 → 通用 → 机种背景图，为 GBA / GB / GBC / FC / SFC / MD
  分别上传 PNG/JPEG，存于 `linkSlot/Backdrops/`，重启后生效；没有时回退壁纸；
- 开机图：`linkSlot/Config/bootlogo.bmp` 可覆盖内置开机图（640×480、24-bit BMP）；
- 主题包可提供自己的 `wallpaper.png` 与字体，优先级高于用户设置。

## 13. 金手指、攻略、介绍与视频

### 13.1 金手指

版本包**不内置**金手指合集。使用方式：

1. 把 `.cht` 放到 `Cheats/<平台>/<核心>/<游戏名>.cht`，例如
   `Cheats/GBA/mgba/星之卡比1 梦之泉.cht`；
2. 或在 Web 游戏详情 → 内容 → 金手指文件，上传 `.cht`（≤ 1 MB）或填写路径；
3. 游戏内 M → 金手指开关。

路径规则：

- GBA：`Cheats/GBA/mgba/`、`Cheats/GBA/gpsp/`、`Cheats/GBA/armgba/`；
- GB / GBC：`Cheats/GB/mgba/`、`Cheats/GBC/mgba/`；
- FC：`Cheats/FC/fceumm/`、`Cheats/FC/nestopia/`；
- SFC：`Cheats/SFC/snes9x/`、`Cheats/SFC/supafaust/`；
- MD：`Cheats/MD/genesis_plus_gx/`。

核心没有自己的金手指目录时（例如 armGBA），会回退默认核心的目录。
Web 里留空路径会恢复默认 `Cheats/<平台>/<核心>/<游戏名>.cht`；拒绝绝对路径、
`..`、反斜杠、非 `.cht` 文件。

### 13.2 攻略

- `Guides/<平台>/<游戏名>.txt` 或 `.epub`；
- Web 游戏详情可填写其他路径或直接上传 `.txt/.epub`；
- 阅读页支持逐行滚动、翻页、回到开头、滚动条、记住位置；
- EPUB 图片单独成页；脚本/样式忽略；
- 没有攻略时提示「暂无攻略」。

### 13.3 介绍与演示视频

- `Info/<平台>/<游戏名>.txt`（UTF-8）；
- `Info/<平台>/<游戏名>.mp4`（H.264）；
- Web → 游戏库 → 游戏详情 → 内容 → 上传介绍 `.txt`（≤ 256 KB）或视频 `.mp4`
  （受单文件上传上限限制）；
- 介绍页最多显示约 4000 字；视频边解码边播放，失败时显示封面；
- 没有介绍时显示「暂无游戏介绍」。

## 14. Mod

### 14.1 是否自带 mod

**版本包不内置任何 mod**，`linkSlot/mods/` 只有说明文件。需要时从可信来源下载
独立 mod 包，通过 Web 安装。常见示例（均需单独安装，具体以各 mod 说明为准）：
GBAStation 电池存档同步、SaveDeck 电池存档桥、AI 游戏资料补全、旧版元数据迁移、
天马G 游戏信息导入等。

### 14.2 安装

- 推荐：Web → **扩展** → **mods 列表** → **导入**，选择完整 mod ZIP；
- 也可把 mod 目录复制到 `linkSlot/mods/<mod-id>/`。

mod 结构：

```text
linkSlot/mods/<mod-id>/
├─ mod.json                 # schema=2、name、version、author、enabled、order
├─ README.md
├─ web/index.html           # 管理页（必需，才能从 Web 管理）
├─ config.json              # 可选
├─ actions/<action-id>/
│  ├─ action.json           # schema=1、name、timing、enabled、order、capabilities、ui
│  ├─ main.lua              # Lua 5.4，≤ 256 KiB
│  └─ sticker.png           # 可选，长按 Y 卡片贴纸
└─ sticker.png              # 可选，mod 级贴纸
```

- `<mod-id>` / `<action-id>` 只能用小写字母、数字、`_`、`-`，并以字母或数字开头；
- 发布包不覆盖 `linkSlot/mods/`；mod 不参与云同步。

### 14.3 动作时机

`action.json` 的 `timing`：

- `before_upload` / `after_upload`；
- `before_download` / `after_download`；
- `after_sync`：整次同步完成后运行一次；
- `after_boot`：开机后运行；
- `manual`：不在云同步中运行，登记到长按 Y 的选择卡。

同一时机的动作按 mod 的 `order`、动作的 `order`、名称排序。`order` 数字越小越优先；
它决定同一时机动作的执行顺序和长按 Y 卡片顺序，但不再决定谁「抢到」长按 Y。

### 14.4 手动动作

- 有启用的 `manual` 动作时，长按 Y 会先弹出卡片：内置「同步云存档」+ 每个手动
  动作一张；
- 左右选择，A 开始，B 关闭；没有手动动作时直接云同步；
- 动作可以用 `mods.choose{...}` 在设备上弹 2–5 个选项，A 确认、B 取消；
- 动作可以上报真实进度（`mods.progress`），同步动画会显示；
- 声明了 `ui.animation = "cloud_sync"` 的动作会复用云同步的卡座/导轨/阶段轨；
  没有 `ui` 的动作使用简洁暗幕。

### 14.5 设备端与 Web 管理

- 设备：**M → 系统 → mod 管理**；上下选择、A 启用/停用、左右调优先级、B 返回；
- Web：**扩展 → mods 列表**：
  - 表格显示名称、作者、是否启用；点击一行查看 README、打开 mod 自己的管理页；
  - **权限**：mod 在 `mod.json` 或 `action.json` 中声明能力，用户勾选后保存授权；
    「一键赋权」可勾选全部声明能力；
  - **卸载**：永久删除整个 mod 目录；
  - **导出**：把全部完整 mod 打包为 ZIP 备份；
  - **开发文档**：打开独立文档页，或导出 API、AI 提示词、Web Bridge、模板 ZIP；
- mod 管理页在沙箱 iframe 中运行，只能通过受限 API 操作当前 mod。

### 14.6 能力与安全

mod 默认不能直接访问任意路径；只有被授予的能力才会暴露受限接口。能力包括
`saves/states` 读写、自身目录、WebDAV 读写、`library:write`、`ui:confirm`、
`network:read/connect`、`sync:read/run`、`files:any`、`packs:install`、
`rom:manage`、`crypto:use` 等。

- 只启用可信 mod；不要运行来源不明的 `main.lua`；
- 启用前备份存档；
- 联机中或卡只读时不能修改 mod；
- 授权记录在 `linkSlot/Config/mod_permissions.toml`，位于 mod 目录之外；
- 加密密钥在 Web **设置 → 维护 → 加密密钥**管理；修改后旧密钥加密的数据无法解密。

## 15. 网络与 Web 管理

### 15.1 WiFi

- 入口：**M → 网络 → WiFi 连接**，或 Web **设置 → 网络**；
- 设备端：开关、扫描（Y 刷新）、已保存网络、手动输入隐藏网络、密码键盘；
- Web 端：当前网络、保存 WiFi、已保存 WiFi（连接/忘记）、扫描附近 WiFi；
- Web 保存 WiFi 只保存凭据，不切换当前网络；设备端可选择已保存网络连接；
- 切换 WiFi 会短暂断开网页；设备 IP 变化后需用新地址重新打开；
- WiFi 自动关闭见 6.6；
- 热点频段见 6.6，只在联机/传输使用。

### 15.2 启动网络服务器

- 入口：**M → 网络 → 启动网络服务器**；
- 启动前检查 WiFi 是否已连接并取得 IP；未连接时提示先连接；
- 成功后在 8080–8089 中选一个空闲端口启动，弹窗显示
  `http://<设备 IP>:<端口>`；
- 关闭弹窗（B / A / M）即停止服务；设备休眠、关机、重启时也会停止；
- 页面与静态资源全部内嵌在程序中，不加载外部 CDN。

### 15.3 Web 页面

顶级导航 7 项：**概览 / 游戏库 / 存档 / 云同步 / 扩展 / 文件 / 设置**；
成就属于游戏库内的视图，网络/维护/关于属于设置内的子 tab。

| 页面 | 内容 |
|---|---|
| 概览 | WiFi、访问地址、游戏数量、存档数量、跨设备总时长、设备可写状态、最近日志 |
| 游戏库 | 游戏 / 成就两个视图；平台筛选、搜索、添加游戏、导入/导出合集；每批 40 个 |
| 存档 | 即时存档与电池存档；搜索、排序、下载、上传覆盖、删除、立即同步；每批 10 个 |
| 云同步 | 多个 WebDAV、当前生效、测试连接、同步缓存、按单元立即同步 |
| 扩展 | 扩展包 / mods 列表两个 tab；安装/卸载/批量、权限、文档 |
| 文件 | 浏览存储卡、上传、下载、预览、重命名、移动、新建文件夹、删除、搜索、排序 |
| 设置 | 通用 / 网络 / 维护 / 关于 |

**概览**：5 张统计卡（WiFi、访问地址、游戏、游戏总时长、设备状态）与「最近日志」。

**游戏库**：

- 工具栏：刷新、平台筛选（全部/GBA/GB/GBC/FC/SFC/MD）、搜索、添加游戏、
  导入游戏/合集、导出合集；
- 添加游戏：选择机种并上传一个 ROM；同名或同内容会拒绝；
- 导入/导出合集：ZIP 根清单 `linkSlot-collection.json`；平台导出文件在
  `Exports/linkslot-<平台>-<时间戳>.zip`；导入按 8 MB 分片上传，相同内容的 ROM
  跳过，同名但内容不同会覆盖；如果导入的单个游戏包内含金手指、电池存档、即时
  存档或游戏时长，会覆盖同名内容，导入前请先备份；
- 游戏卡片点击进入详情，四个页签：
  - **概览**：平台、ROM 路径、大小、SHA-256（可复制）、已解锁成就；
  - **外观**：卡带颜色、快速前盖、前盖编辑器、FC/NES 模型；
  - **内容**：金手指路径/上传、介绍 `.txt`、视频 `.mp4`、攻略 `.txt/.epub`；
  - **操作**：导出游戏包（不含存档）、在浏览器游玩、替换 ROM、重命名、删除
    ROM（保留存档）；
- 重命名会同步移动存档、状态、封面、攻略、金手指、前盖，并更新最近游玩/收藏。

**存档**：

- 每个单元显示游戏名、平台·核心、游戏时长（本机/跨设备）；
- 即时存档显示缩略图、恢复点/历史时间、下载/上传覆盖/删除；
- 电池存档显示 `.sav/.srm` 文件、下载/上传覆盖/删除；
- 上传时可选择「即时存档 / 电池存档」，文件只写入当前游戏；
- 删除只删除本机文件，不影响云同步或远端备份；删除 `.state` 会一并删除同名
  `.png` 缩略图；
- 每个单元有「立即同步」。

**云同步**：

- 同步方式列表：名称、地址、当前生效、编辑；至少保留一个；
- 编辑表单见 10.1；测试连接使用当前输入；
- 同步缓存表：单元、版本、最近同步、远端（地址匹配/已变）、立即同步；
- 页面没有「批量同步」按钮；同步按单元执行；
- 冲突需回设备处理；Web 不提供覆盖方向选择。

**扩展**：

- **扩展包**：上传 `.lsp`、选择文件夹批量安装、按核心包/成就包筛选、查看
  许可证/来源/最低版本/文件清单、卸载；
- **mods 列表**：导入/导出 mod ZIP、查看 README、打开 mod 管理页、权限、
  一键赋权、卸载、开发文档；
- 没有内置 mod；安装包只带 `mods/README.txt`。

**文件**：

- 浏览存储卡根目录；Config 目录不显示，System 目录只读；
- 支持上传（多选）、新建文件夹、重命名、移动、删除、预览图片/文本、复制路径；
- 搜索与排序（名称/大小/修改时间）；单目录最多显示 2000 项；
- 普通文件下载上限 64 MB，`Exports/*.zip` 上限 256 MB；文本预览上限 1 MB；
- `linkSlot/Logs/` 下的 `.log` 下载时会改名为 `<原名>_<设备型号>_<日期>.log`；
- 路径穿越、符号链接、受保护目录的祖先改名/移动会被拒绝。

**设置**：

- **通用**：语言（中文/English，立即生效）、时间同步（设备时间/时区、
  用浏览器时间校准、联网强制同步时间和时区）、机种背景图；
- **网络**：当前网络、保存 WiFi、已保存 WiFi、可用网络；
- **维护**：上传系统更新、上传限制（默认 32 MB，1–256 MB）、加密密钥、
  日志导出、日志清理、服务日志（最后 200 行）与日志级别；
- **关于**：Slot 版本、linkSlot CLI 版本、Web 服务端口、访问地址、许可证、
  使用说明。

### 15.4 浏览器游玩

Web 游戏详情 → 操作 → **在浏览器游玩**，新标签打开
`/play?rom=Games/<平台>/<文件>`。

- 支持 **GBA（mGBA）/ GB / GBC（Gambatte）/ FC（FCEUmm）**；
  SFC / MD 暂不支持浏览器游玩；
- 设备只负责提供 ROM 和 `.sav`，模拟器在浏览器中运行，不占设备 CPU；
- 电池存档自动读写：打开时读取 `Saves/<平台>/<游戏>.sav`；暂停、退出、切后台
  以及每 5 分钟写回；
- 写回前保留旧文件为 `.sav.bak`；如果设备上的存档在页面打开后被改过，会拒绝
  写回并提示；
- 浏览器和掌机不要同时玩同一个游戏；
- FC 可开「双人同屏」：P1 为 `W/A/S/D` 移动，`J/K/L` 对应 B/A/连发 A，
  `U/I` 对应 Select/Start；P2 为方向键移动，`1/2` 为 B/A、`3/4` 为连发 A/B、
  `5/6` 为 Select/Start；
- 手柄：先连接的手柄是 1P，第二个手柄在双人模式下自动成为 2P；
- 支持暂停、重新开始、退出、1×/2×/4× 速度、画面缩放与全屏。

### 15.5 安全与写入限制

- Web 服务**无登录鉴权**，只监听局域网；请只在可信网络使用，不要暴露到公网；
- 所有写操作要求请求头 `X-Slot-Web: 1`；
- 设备在游戏中或同步中时写操作返回 409，页面进入只读状态；只读仍可浏览、
  下载存档；
- 并发连接上限 8 个，超出返回 503；
- 单文件上传上限默认 32 MB，可在设置 → 维护调整到 1–256 MB；
- 文件页不显示 `linkSlot/Config/`，`System/` 只读；路径穿越与符号链接逃逸会被拒绝；
- 上传采用临时文件 + 原子替换。

## 16. 系统与维护

### 16.1 时间

- **M → 系统 → 日期与时间**：设置日期、时间和时区（UTC−720 到 UTC+840，
  默认 `+08:00`）；
- Wi-Fi 取得 IP 后后台 SNTP 校时，依次尝试 `pool.ntp.org`、
  `time.cloudflare.com`、`ntp.aliyun.com`；UDP 123，2 秒超时，不阻塞 UI；
- SNTP 只更新 UTC；时区由用户设置，或按公网 IP 自动校正。Web 设置 → 通用 →
  时间同步可打开「联网时强制同步时间和时区」（默认关闭，设备显式时区优先）；
  关闭时只有从未手动设置过时区的设备才会自动采用网络时区；
- 失败每 10 分钟重试，成功后 6 小时内不重复校时；
- 读到的时间早于 2020 时判定为 RTC 掉电，先用固件构建时间顶上，等联网校时或
  手动设置覆盖；
- 首次开机不再强制弹出时区选择。

### 16.2 休眠、关机与修复

- 合盖进入休眠，开盖唤醒；持续休眠达到「合盖自动关机」所选时间后保存并关机；
- 短按电源休眠/唤醒；长按约 1 秒打开电源菜单：**重新启动 / 关机 / 修复存储卡**；
- 关机/重启前会先 `sync`、卸载 WiFi 驱动，再次 `sync`，避免存档未落盘；
- **只读卡修复**：
  - 主界面在卡只读时按 **SELECT + START** 直接进入修复；
  - 或电源菜单 → 修复存储卡；
  - 修复脚本会调用 `fsck.fat` / `fsck.exfat`，最多 6 轮，完成后重启；
  - 结果在下次启动提示：未发现问题 / 修复完成 / 修复失败；
  - 修复前建议先备份存档。

### 16.3 日志

| 日志 | 内容 |
|---|---|
| `linkSlot/Logs/linkSlot.log` | 云同步、WiFi、成就等主日志；级别由 `log_level.txt` 控制 |
| `linkSlot/Logs/slot.log` | 前端 stdout/stderr |
| `linkSlot/Logs/slot-startup-r2.log` | 启动脚本日志，每行带 uptime |
| `linkSlot/Logs/slot-library.log` | 游戏扫描报告 |
| `linkSlot/Logs/input-trace.log` | 输入追踪（调试用） |
| `linkSlot/Logs/crash/` | 核心崩溃记录，最多保留最近 5 份 |

- Web → 设置 → 维护 → **一键导出日志**：把 `Logs/`（含 `crash/`）和
  `version.json` 打成 ZIP，文件名带设备型号与日期；
- **一键清理日志**：清空 `Logs/` 下全部日志（含 crash），不可恢复；
- 日志级别：错误 / 警告 / 信息 / 调试；调试会记录 WiFi 扫描、关联、DHCP 等细节；
- 排查启动慢时，可同时提供 `slot-startup-r2.log` 与 `slot.log`，区分启动脚本、
  SD 卡扫描、封面、壁纸各占多久。

### 16.4 语言、设备名与关于

- 语言：中文 / English，设备、Web、mod 共用 `linkSlot/Config/language.txt`；
- 设备名：`linkSlot/Config/device_name.txt`，最多 16 字节；用于联机页显示
  「对方：xxx」；缺省用系统 hostname；
- 关于页：当前项目版本、上游 Slot 版本、构建时间、本机名称、作者、原项目、
  感谢名单与免费使用声明；短按 A 感谢名单，长按 A 约 1 秒设为调试日志。

### 16.5 桌面版

仓库还提供桌面（host）构建，用于开发和快速查看 UI：

```sh
sh build/dist.sh host
```

- 生成 `target/release/slot`（前端）与 `target/debug/linkSlot`（CLI，默认无
  TLS/Lua）；
- 桌面版可以使用 Web 管理服务器（用本机局域网地址，离线回退 `127.0.0.1`），
  云同步直接调用本机 CLI；
- 桌面版没有 WiFi 管理、自动关闭、真实电源/修复逻辑；联机默认走 LAN 回环；
- 需要 HTTPS 云同步时，请单独构建带 `tls-rustls` 的 CLI，并通过 `LINKSLOT_CLI`
  或可执行文件位置让前端找到它。

## 17. 常见问题与限制

### 17.1 硬限制

- **不支持 `.fds`**；FC 只接受 `.nes`。
- **浏览器游玩只支持 GBA / GB / GBC / FC**；SFC / MD 只能上传/管理或在掌机上玩。
- **SFC 的 supafaust 不随包**；默认核心是 snes9x。
- **GBA 的 mGBA 只支持电缆联机**；gpSP / armGBA 使用 netpacket 且受白名单限制；
  马里奥赛车等电缆游戏请用 mGBA。
- **gpSP / armGBA 不传主机进度**；两端需同一构建。
- **GB / GBC 联机**取决于核心与游戏支持。
- **Web 无登录**，只适合家庭局域网；不要暴露到公网。
- **同一时间只有一个 WebDAV 生效**。
- **Web 端不能解决同步冲突**，必须回设备选择覆盖方向。
- **`push` / `pull` 只处理即时存档**；电池存档请用 `sync` / `--only sav` / 设备
  同步 / Web 同步。
- **导出的单游戏包不含存档**；导入第三方包时如果包内带存档，会覆盖同名文件，
  请先备份。
- **版本包不内置金手指、mod、成就包**；需要时自行安装。
- **游戏名 = ROM 文件名**；改名请用 Web，避免存档目录对不上。
- **旧版按游戏名的云端目录不会自动迁移**。
- **整张卡只有 1 个 ROM 时**，开机会直接进入该游戏且不能退卡，因此主界面长按 Y
  同步不可用；放第二张 ROM 后恢复正常。

### 17.2 常见问题

**ROM 放进去了但主界面没有**

- 确认目录是 `Games/GBA`、`Games/GB` 等，扩展名正确；
- 手动拷入后重启 App（或在 Web 点刷新游戏库）；
- 同名/同内容 ROM 可能被去重；Web 添加会提示；
- 卡只读或路径含非法字符时扫描会跳过。

**没有封面 / 介绍 / 视频**

- 封面放 `Labels/<平台>/<游戏名>.png`；介绍/视频放 `Info/...`；
- 也可以在 Web 游戏详情里上传；
- 文件名的「游戏名」必须与 ROM 文件名一致。

**金手指不显示**

- 版本包不带金手指；确认 `.cht` 放在 `Cheats/<平台>/<核心>/<游戏名>.cht`；
- 当前核心必须匹配；gpSP 有 20 项上限；
- 游戏内菜单 → 金手指，条目默认关闭。

**联机失败**

- 确认双方机种、核心、ROM 内容一致；
- GBA mGBA 只能电缆；gpSP/armGBA 只接受白名单游戏；
- armGBA 两端需同一构建；
- FC/SFC/MD 未连 WiFi 时先连接；同一 Wi-Fi 模式需要同一路由器；
- 热点频段两端必须相同；
- 联机中不能开金手指、不能同步。

**云同步报冲突**

- 冲突不会自动覆盖；回设备主界面，按页面选择「覆盖本地/覆盖云端」；
- 云端被其他设备更新时会提示重新选择方向；
- 同步中不要关机或开联机。

**Web 页面打不开**

- 确认手机/电脑与设备在同一 WiFi；
- 确认弹窗里显示了地址和端口，且弹窗没有关闭；
- 设备 IP 变化后使用新地址；
- 8080–8089 都被占用时启动会失败。

**Web 写入被拒绝（409）**

- 设备正在游戏或同步中；回到主界面、结束同步后再写；
- 文件页的 `System/` 只读，`linkSlot/Config/` 不显示；
- 写请求必须来自内置页面（带 `X-Slot-Web: 1`）。

**时间不对**

- 联网后自动 SNTP；时区在 系统 → 日期与时间 设置；
- 可在 Web 设置 → 通用 → 时间同步用浏览器时间校准；
- 打开「联网时强制同步时间和时区」会覆盖本机时区；
- RTC 掉电时会先用构建时间。

**存储卡只读**

- 主界面按 SELECT + START，或电源菜单 → 修复存储卡；
- 修复前备份存档；修复完成会自动重启并提示结果。

**Web 升级后版本没变**

- 升级包必须带 `linkSlot/version.json`；
- 网页只上传暂存，需在设备 **系统 → 安装更新** 确认；
- 正式包只接受更高版本；开发构建允许同版本重装。

**成就没有解锁**

- 全局/每 ROM 成就需要实际游玩、启动次数等条件；
- RA 成就需要安装对应成就包，且 ROM 的 SHA-256 与定义匹配；
- 成就页在长按 B 的介绍页里按 Y 打开。

## 18. 从源码构建

完整的构建说明见 [build/README.md](build/README.md)。要求：

- Rust 1.96（`rust-toolchain.toml` 自动拉取）；
- aarch64 Linux（glibc ≤ 2.31）或 Docker（支持 `linux/arm64`，x86_64 需 QEMU）；
- git、curl、cmake、make、g++、python3、file、zip、binutils；
- 至少 40 GB 空闲磁盘。

常用命令：

```sh
# SD 卡整包（容器内构建）→ artifacts/linkslot/
sh build/dist.sh h700

# 发布门槛：许可证 / 对应源码 / GLIBC
sh build/dist.sh h700 --release

# 只组装、不打包
sh build/dist.sh h700 --no-package

# 复用已构建核心（调试 UI 用）
sh build/dist.sh h700 --no-cores

# 桌面版
sh build/dist.sh host

# 干净树验证
sh build/clean-build.sh

# 校验产物
sh build/verify.sh artifacts/linkslot --release

# 打包 zip（可复现）
python3 build/package.py --dir artifacts/linkslot --out artifacts/linkslot-v1.0.49-h700.zip
```

Windows 可用：

```powershell
powershell -ExecutionPolicy Bypass -File build\dist.ps1
```

产物结构：

```text
artifacts/linkslot/
├─ Games/ Saves/ States/ Labels/ Guides/ Info/ Cheats/ Overlay/
│  Wallpapers/ Music/ BIOS/ Bootlogos/     # 公共区
├─ linkSlot/
│  ├─ Config/                               # 设置与状态
│  ├─ Fronts/ Metadata/ mods/
│  ├─ Logs/
│  └─ version.json
├─ System/
│  ├─ launch_frontend.sh
│  └─ linkSlot/
│     ├─ bin/ linkslot、linkslot_sync、fsck.exfat
│     ├─ shell/
│     ├─ cores/
│     ├─ assets/
│     └─ licenses/
└─ README-ZH-CN.md
```

仓库结构：

| 路径 | 内容 |
|---|---|
| `crates/` | Rust workspace（`slot` 前端、`linkslot` CLI、`slot-model`、`slot-ui` 等） |
| `card/` | 卡内脚本与默认资源 |
| `cores/` | 核心构建脚本与补丁 |
| `manifest/` | 核心与打包清单 |
| `packs/` | LSP 扩展包模板 |
| `build/` | 构建、打包、校验脚本 |
| `translations/` | 中英文文案（编译进二进制） |
| `licenses/` | 第三方许可证与对应源码 |

测试：

```sh
cargo fmt --all -- --check
cargo clippy --workspace --all-targets
cargo test --workspace --no-fail-fast
python3 build/check-deps.py --enforce
sh build/verify.sh artifacts/linkslot --release
```

版本号统一在 `Cargo.toml` 的 `[workspace.package] version`；发布时同步更新
`CHANGELOG.md` 与本手册顶部的版本行，并重新出包。

LSP 扩展包打包：

```sh
python3 build/pack_lsp.py \
  --meta packs/supafaust/pack.json \
  --payload System/linkSlot/cores/supafaust/supafaust_libretro.so=vendor/supafaust_libretro.so \
  --out dist/packs/linkslot-pack-supafaust-v1.0.0.lsp
```

成就包使用独立工具 `linkslot-ra` 生成，详见
[EXTENSION-PACKS-ZH-CN.md](EXTENSION-PACKS-ZH-CN.md)。
